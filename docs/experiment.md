## Перевірка гіпотези

* Зміна медіанного часу job-а analysis при P=32 відносно P=8: **+0.2%** (гіпотеза: ≤ −15%) → НЕ підтверджено.
* Зміна сумарного обсягу shuffle: **+7.2%** (гіпотеза: |зміна| ≤ 10%) → підтверджено.
* Частка stage A в часі job-а: 97% (P=8), 96% (P=32). P змінює лише stage B і C.
